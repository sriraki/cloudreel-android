## Screen Flow Sequence

1. **Splash Screen (0.0s – 2.5s)**
   - Centered CloudReel infinity emblem (`#7C3AED` to `#EC4899` gradient)
   - "CloudReel" brand wordmark
   - Unconditional navigation to Home

2. **Home Screen (Light Mode) (2.5s – 6.0s)**
   - Top-left unified CloudReel logo and top-right theme toggle
   - Heading: "Welcome to CloudReel"
   - Subtitle: "Choose how you want to connect."
   - **Four Primary Options:**
     1. Start as Host
     2. Join as Participant
     3. Streamer
     4. Relay

3. **Start as Host (Shared Entry Screen) (6.0s – 9.0s)**
   - Mode: Host Mode
   - Title: "Start as Host"
   - Subtitle: "Enter the session URL or code to continue."
   - Input validation and "Continue as Host" action

4. **Host Workflow Screen (9.0s – 12.0s)**
   - Live Room Hub (`CR-8492-HOST`) with room code copy
   - Real-time telemetry: 1080p60, 4 participants, 4.2 Mbps uplink, 22ms latency
   - Broadcast controls (Mute, Camera Pause, End Broadcast)

5. **Join as Participant (Shared Entry Screen) (12.0s – 15.0s)**
   - Mode: Participant Mode
   - Title: "Join a Session"
   - Subtitle: "Enter the session URL or code to join."
   - "Join Session" action

6. **Participant Workflow Screen (15.0s – 18.0s)**
   - Low-latency viewport with 1080p60 stream and 18ms latency badge
   - Stream audio toggle, fullscreen, and "Leave Session" action

7. **Streamer Authentication Required (18.0s – 21.0s)**
   - Prompted when unauthenticated user selects Streamer
   - Login / Sign Up with CloudReel styling
   - Upon successful sign-in, automatically opens Streamer screen

8. **Existing Streamer Screen (21.0s – 24.0s)**
   - Live camera broadcast feed with multi-network bonding telemetry

9. **Existing Relay Screen (24.0s – 27.0s)**
   - Cellular contribution node (no login required)
   - Battery & data usage telemetry

10. **Home Screen (Dark Mode) (27.0s – 32.0s)**
    - Seamless theme toggle demonstrating dark mode styling and accessible contrast
